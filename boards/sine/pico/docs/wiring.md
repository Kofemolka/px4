
# UART0
* TX - GPI0
* RX - GPI1


# SPI0

| RP2040         | BMI160 |
| -------------- | ------ |
| CLK	4 GPIO2  | SCX    |
| MOSI	5 GPIO3  | SDX    |
| MISO	6 GPIO4  | SAO    |
| CS0	7 GPIO5  | CS     |

# SPI1

| RP2040          | BMI323 |
| --------------- | ------ |
| CLK	13 GPIO10 | SCL    |
| MOSI	14 GPIO11 | SDA    |
| MISO	15 GPIO12 | SAO    |
| CS1	16 GPIO13 | CS     |
